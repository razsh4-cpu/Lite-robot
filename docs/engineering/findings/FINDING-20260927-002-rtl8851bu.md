# FINDING-20260927-002 — rtl8851bu evidence

Kernel evidence included out-of-tree `rtl8851bu` UBSAN array-index errors and
concurrent station/AP-style interfaces during intermittent network loss. A
policy to pin NetworkManager, disable Wi-Fi power saving, and preserve the
station address was prepared, but long-soak closure is absent.

- Evidence: [Day-2 closeout](../../HIGH_LEVEL_NAV2_CLOSEOUT_2026-09-27.md) and
  [operations KB](../../operations/ENGINEERING_KNOWLEDGE_BASE.md).
- Impact: Mini-PC can appear unreachable while Linux crash evidence is absent.
- Current status: partial mitigation; long network/reboot/mission-load soak
  remains required.
- DO NOT REPEAT: attribute every SSH loss to this driver; resource starvation
  and bridge/address faults have separate evidence.
